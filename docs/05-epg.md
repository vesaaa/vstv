# 节目单与回看

[返回目录](README.md)

## 节目单从哪里来

在 **设置 → 节目单** 里选：

| 来源 | 说明 |
|------|------|
| **跟随直播源**（默认） | 用直播源里写的节目单地址（M3U 第一行的 `x-tvg-url`）。大多数直播源都带，不用设置 |
| **内置** | 直播源没带节目单时，选一个内置的节目单 |
| **自定义** | 填自己的 XMLTV 节目单地址；用手机扫码填写比较方便。自己添加的可以长按删除 |

节目单支持 XMLTV 格式，`.xml` 和 `.xml.gz` 都可以。直播源写了多个节目单地址时，一个打不开会自动试下一个。

## 什么时候更新

- **每天最早更新时间**：每天不到这个时间不重新下载，避免白天反复下载。
- **刷新节目单**：清掉缓存，马上重新下载。

第一次下载节目单时画面可能会卡一下，属于正常现象。

## 看节目单

- 打开选台列表，**在频道上按右键**，就能看这个频道今天、明天、后天的节目。
- 快捷菜单里的「节目单」显示当前频道的节目。
- 设置 → 界面 → **节目进度**：在频道列表里显示当前节目播到哪儿了。

## 回看

支持回看的频道，节目单里已经播过的节目会标「回看」，选中按确认键就从头开始播。

- 回看时可以拖动进度、按左 / 右键快进快退。
- 想回到直播，在快捷菜单里选「返回直播」。
- 最多可以回看 7 天，具体取决于直播源。

### 哪些频道能回看

要直播源支持才行。VsTV 认识以下几种：

- M3U 里写了 `catchup`、`catchup-source` 回看模板的频道（`append`、`default`、`flussonic`、`xc` 等常见类型）。
- 运营商和 rtp2httpd 常用的 `playseek=开始时间-结束时间` 方式。
- 运营商的 RTSP 回看。
- 地址本身支持时移（DVR）的 HLS 频道。

快捷菜单的「节目单」里会显示当前频道「可回看」还是「不支持」。

## 时移

支持回看的频道，在快捷菜单里还能选「回看时长」，比如回看 30 分钟前的直播，错过的内容可以倒回去看。
