# 基本介绍

[返回目录](README.md)

## VsTV 是什么

VsTV 是一个直播播放器：你添加直播源后，就可以在电视上选台、换台、看节目单、回看，还能分屏、小窗和看 AI 字幕。

- **小巧**：常规安装包不到 10MB，低配盒子也能流畅运行。
- **纯净**：没有广告，不需要谷歌服务。
- **不带节目**：VsTV 不内置任何直播源，需要自己添加。

## 适用设备

- 常见品牌的电视和盒子（TCL、海信、酷开、小米、华为智慧屏、荣耀等），以及安卓手机、平板。
- Android 5 及以上。实际播放效果取决于设备的解码能力和直播源本身。

## 选哪个安装包

在 [Releases](https://github.com/vesaaa/vstv/releases) 下载。每个版本有四个安装包：

| 安装包 | 适合谁 |
|------|------|
| `vstv-<版本>-arm.apk` | **默认选这个**，绝大多数电视、盒子、手机都用它 |
| `vstv-<版本>-arm-av3a.apk` | 菁彩声版：多了菁彩声（Audio Vivid）音频解码，体积大一些。要看菁彩声频道时装它，可以直接覆盖 arm 版 |
| `vstv-<版本>-x86_64.apk` | x86 设备，比如电脑上的安卓模拟器 |
| `vstv-<版本>-HarmonyOS.apk` | 华为智慧屏等需要不同包名的设备，桌面上叫「Z视介」；和其他版本数据不互通，不要混装 |

安装时如果提示「禁止安装未知应用」，到系统设置里允许用来安装的应用（文件管理器、U 盘助手等）安装未知应用。

## 第一次打开

第一次打开会自动弹出「添加直播源」，选一种方式添加即可，详见 [添加直播源的四种方法](03-add-source.md)。

## 怎么操作

| 操作 | 遥控器 | 手机 / 平板 |
|------|--------|------------|
| 换台 | 上 / 下键；打开「数字选台」后也可以按数字键 | 上下滑动 |
| 切换线路 | 左 / 右键 | 左右滑动（回看时是快进快退） |
| 打开选台列表 | 确认键 | 单击 |
| 打开快捷菜单 | 菜单键，或长按下键 | 双击 |
| 快速切换直播源 | 长按确认键 | 长按约 0.8 秒 |
| 返回 / 关闭面板 | 返回键 | 返回手势 |

### 选台列表

按确认键打开。左边是分组，中间是频道，**在频道上按右键**可以看这个频道的节目单。

- 在频道上**长按确认键**：加入或移出精选。
- 在分组上**长按确认键**：隐藏分组、把整个分组加入精选、分享直播源。

### 快捷菜单

按菜单键（或长按下键）打开，最上面是当前频道的画质、音质徽章，下面是常用功能：

- **直播源**：切换到别的直播源
- **节目单**：看当前频道的节目，支持回看的可以直接点开
- **多线路**：同一个频道有几条线路时，在这里换
- **画面**：切换画面比例
- **分屏播放**：左右分屏或四宫格
- **轨道选择**：切换音轨、字幕
- **菁彩视听**：声道输出方式
- **AI 字幕**：给当前频道打开或关闭 AI 字幕
- **解码与码流**：看当前播放的编码、分辨率、解码方式、码率等
- **主菜单**：打开设置

### 设置

从快捷菜单的「主菜单」进入。左边是 9 个分类：直播源、节目单、播放、界面、精选与合并、AI 字幕、网络、高级、关于。

在左边菜单上下移动就能看到右边的内容；按右键进入，按左键或返回键回到菜单，在菜单上再按返回关闭设置。

很多设置也可以用手机改，见 [手机访问与网络](10-network.md)。
