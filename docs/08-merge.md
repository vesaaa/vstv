常见情况：央视在一个直播源里画质最好，本地台在另一个直播源里，体育台又在第三个。每次切换直播源很麻烦。

**扩展频道**可以把各个直播源里你精选的频道汇集到一个「扩展频道」分组里，不管当前用的是哪个直播源，这个分组都在，几个直播源的台合在一起看。

## 怎么用

1. **打开扩展频道**：设置 → 精选与合并 → 打开「启用扩展频道」。
2. **切到第一个直播源**，把想要的频道加入精选（在频道上长按确认键）。
3. 到 **设置 → 精选与合并 → 更新扩展频道**，把这个直播源的精选放进扩展频道。
4. **切到第二个直播源**，同样精选想要的频道，再点一次「更新扩展频道」。
5. 其他直播源依此类推。

完成后，选台列表里会多一个「扩展频道」分组，里面是各个直播源放进来的频道。

## 说明

- 「更新扩展频道」只更新**当前直播源**放进去的那部分，不影响其他直播源放进来的频道。某个直播源的精选改了，切到它再点一次更新即可。
- 设置里会显示扩展频道目前来自几个直播源、一共多少个频道。
- 扩展频道保存了频道的播放地址和请求头，不需要切回原来的直播源就能播。
- **清空扩展频道**：删除扩展频道里的所有频道。
- 「扩展频道」和「精选频道」是自动生成的分组，不能隐藏或再加入精选，但可以分享给别人。

## 和同名合并的区别

- **同名合并**是自动的：同一个直播源、同一个分组里同名的频道，合成一个频道的多条线路，用左右键切换。
- **扩展频道**是手动挑的：把不同直播源里的频道放到同一个分组。
