直播源里动辄几百个台，家里老人、小孩经常「找不到台」。把常看的几个台加入**精选**，再打开**只看精选**，电视上就只剩这几个台，上下换台也只在它们之间切换。

## 第一步：加入精选

打开选台列表，在频道上**长按确认键**，就加入了精选；再长按一次是移出。

整个分组都要的话，在分组上长按确认键，选「添加到精选频道」。

加入后，选台列表里会多一个「精选频道」分组。

> 精选会把频道的播放地址和请求头一起保存下来，即使以后删掉了这个直播源，精选的频道照样能播。

## 第二步：打开只看精选

**设置 → 精选与合并 → 只看精选**，打开。

之后：

- 选台列表里只显示精选的频道，其他频道都隐藏。
- 上下换台只在精选里切换。

要先精选至少一个频道才能打开。想恢复显示全部频道，把「只看精选」关掉就行。

## 管理精选

在 **设置 → 精选与合并** 里：

| 设置 | 说明 |
|------|------|
| 启用精选 | 关掉后不再显示「精选频道」分组 |
| 当前精选 | 看当前直播源精选了多少个频道 |
| 清空全部精选 | 删除所有精选频道 |

精选是**按直播源分开保存**的：每个直播源有自己的精选。想把几个直播源的精选合到一起，看 [多源合并：扩展频道](08-merge.md)。

## 给长辈设置的小建议

1. 先把长辈常看的台都加入精选。
2. 打开「只看精选」。
3. 在 **设置 → 播放** 里打开「开机自启」，开电视就直接是直播。
4. 不会添加直播源的长辈，可以用「请求协助」远程帮他们添加，见 [添加直播源的四种方法](02-add-source.md#四请求协助)。
