# 添加直播源的四种方法

[返回目录](README.md)

第一次打开 VsTV 会自动弹出「添加直播源」。以后要再添加，在 **设置 → 直播源 → 添加直播源** 里操作。

有四种方法，按自己的情况选一种：

| 方法 | 适合 |
|------|------|
| [自动添加](#一自动添加) | 家里有 tvgo 或 rtp2httpd |
| [手机扫码](#二手机扫码) | 直播源地址很长，或者是手机上的文件 |
| [输入地址](#三输入地址) | 地址短，或者电视上已经有直播源文件 |
| [请求协助](#四请求协助) | 自己不会弄，请家人朋友远程帮忙 |

## 一、自动添加

自动查找同一个局域网里的 **tvgo**（默认端口 16677）和 **rtp2httpd**（默认端口 5140），几秒就有结果。

1. 选「自动添加」，等它查找。
2. 列表里选一个，就添加好了，并马上切换过去。

找不到时：

- 确认 tvgo / rtp2httpd 和电视连的是同一个网络。
- 设备在别的网段时，可以在下面选一个网段接着查找。
- 改过端口的，用「输入地址」或「手机扫码」添加。
- rtp2httpd 要先在它的配置里设置好播放列表。

## 二、手机扫码

用手机填写，比用遥控器打字方便得多。

1. 选「手机扫码」，电视上会显示一个二维码。
2. 手机连上和电视**同一个网络**，扫码打开网页。
3. 在网页里填写直播源地址，或者上传手机里的 m3u / txt 文件，点推送。
4. 电视上马上就添加好了。

扫码打不开网页：检查路由器是否开了「访客网络」或「设备隔离」；电视有好几个网络地址时，到 **设置 → 网络 → 扫码用的本机地址** 选手机能连上的那个。

## 三、输入地址

1. 选「输入地址」。
2. 填写直播源地址（http:// 或 https:// 开头，支持 m3u / txt）。
   - 可以先在别处复制地址，再点「粘贴」。
   - 也可以点「本地文件」，选电视上的 m3u / txt 文件。
3. 「名称」可以不填，填了会显示在切换直播源的列表里。
4. 「User-Agent」一般不用填，直播源提供者要求时再填（比如 `aptv`）。
5. 点「保存」。

## 四、请求协助

家里的长辈不会添加？让会弄的家人远程帮忙，只需要报一个 4 位数字。

**电视这边（请求帮忙的人）：**

1. 选「请求协助」，同意说明后，电视上会显示一个 **4 位数字**。
2. 把这个数字告诉帮忙的人（打电话、发微信都行）。数字 5 分钟内有效，过期了可以重新发起。
3. 对方分享后，电视上会显示收到的分组和频道数量，确认是认识的人发的，点「使用」。

**帮忙的人：**

1. 在自己的 VsTV 上，打开选台列表，在频道分组上**长按确认键**，选「分享直播源」。
   也可以在切换直播源的列表里长按某个直播源分享整个直播源。
2. 输入对方电视上的 4 位数字，点「确认分享」。

分享过去的直播源会马上切换使用；以后想换回原来的，在「切换直播源」里选就行。

> 请只分享合法的直播源。分享的内容由分享者自行负责。

## 添加之后

- 可以添加多个直播源，播放时**长按确认键**就能快速切换，见 [直播源管理](04-sources.md)。
- 节目单默认跟着直播源走，一般不用设置，见 [节目单与回看](05-epg.md)。
