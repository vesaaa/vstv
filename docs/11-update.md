# 软件更新

[返回目录](README.md)

## 在线更新

**设置 → 关于 → 应用更新**，短按检查新版本。

- 有新版本时会显示「可更新」，点一下自动下载，下载完弹出系统安装界面，按提示完成即可。
- 会自动下载和你现在装的版本**同一类型**的安装包：装的是菁彩声版，就只会更新到菁彩声版；鸿蒙版只会更新到鸿蒙版。
- VsTV 不会在启动时自动检查更新，需要时自己点一下。

### 点了更新没反应

Android 8 及以上要允许 VsTV「安装未知应用」：到系统设置里找到 VsTV，打开「安装未知应用」权限，再点一次更新。

## 接收测试版

想先用上新功能，可以打开 **设置 → 关于 → 接收测试版**：

- 打开后，检查更新时也会收到测试版。测试版先上新功能，但可能不稳定。
- 关掉后，会等下一个正式版出来再更新。
- 默认关闭。只有菁彩声版（arm-av3a）有这个开关，因为测试版只出这一种安装包。

## 手动下载

所有版本都在 [Releases](https://github.com/vesaaa/vstv/releases)，可以下载安装包用 U 盘或文件管理器安装，直接覆盖安装不会丢设置。选哪个安装包见 [基本介绍](01-introduction.md#选哪个安装包)。
