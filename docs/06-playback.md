# 播放与画面

[返回目录](README.md)

## 画面比例

- **设置 → 播放 → 全局画面比例**：所有频道默认用的比例（原始、自动拉伸等）。
- 快捷菜单的「画面」可以给当前播放临时换一个比例。

## 换台

- **数字选台**：打开后可以用遥控器数字键直接输入频道号。
- **换台反转**：习惯「按上是下一个台」的，可以在这里反过来。
- **开机自启**：开机后自动打开 VsTV。部分电视还要在系统设置里允许 VsTV 自启动。

以上都在 **设置 → 播放** 里。

## 分屏播放

快捷菜单 → **分屏播放**，选「左右分屏」或「四宫格」，最多同时看四路直播。选中哪个画面，换台和声音就跟着哪个画面。退出时选「退出分屏」。

分屏播放不支持 AI 字幕。

## 小窗播放

按主页键、切到别的 App 或点开消息时，VsTV 会用小窗继续播放；点小窗上的全屏按钮回到 VsTV。

在 **设置 → 界面 → 离开时自动小窗播放** 里开关（手机、平板默认开启）。部分电视不支持小窗。

## 画质、音质徽章

打开快捷菜单，频道名下面有一排徽章，一眼看出这个台是什么规格：

- 分辨率：SD、720p HD、1080p FHD、2K、4K UHD、8K UHD
- 动态范围：SDR、HDR10、HLG、杜比视界
- 帧率：50FPS、60FPS 等高帧率
- 视频编码：H.264、H.265、AV1 等
- 音频：杜比全景声、杜比数字+、菁彩声、DTS、5.1 / 7.1 声道、直通

徽章说的是**直播源本身的格式**，设备实际怎么播放看「解码与码流」。

## 解码与码流

快捷菜单 → **解码与码流**，可以看到当前播放的详细信息：

- **视频**：编码和档次、分辨率、帧率（括号里是屏幕刷新率）、画质（HDR 类型、色域、位深）、**解码方式**、标称码率
- **音频**：编码、声道、采样率、解码方式（直通表示交给电视或功放解码）
- **码流**：协议、实时码率、起播耗时、播放地址

「解码」一行会写明是 **硬解**（设备芯片解码，最流畅）、**系统软解** 还是 **FFmpeg 软解**（用处理器解码，4K 时可能卡）。看起来卡顿或画面不对时，先看这里，详见 [常见问题](13-faq.md)。

## 音轨和字幕

快捷菜单 → **轨道选择**，可以切换视频、音频、字幕轨道（直播源提供多条时）。

## 菁彩视听

快捷菜单 → **菁彩视听**：默认按电视或功放的声道自动输出；对白听不清时可以选「强制立体声」。

## 界面

**设置 → 界面** 里可以调：

- **时间显示**：画面右上角什么时候显示时间（不显示、一直显示、整点或半点前后）
- **显示网速**：右下角常驻显示网速
- **列表高亮颜色**：选台列表里选中那一行的颜色（蓝色、绿色、只描边）
- **超时自动关闭界面**：选台和快捷菜单多久不操作就自动关闭
- **界面整体大小**、**界面文字大小**：电视上界面太大或太小时调整
- **桌面图标样式**：经典蓝色图标或深色新图标（电视桌面常常要重启后才换）
- **启动动画**：打开 VsTV 时的一秒多开场动画，按任意键可以跳过；配置低的盒子不放
