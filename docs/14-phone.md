从 2.8.3 起，在手机上打开 VsTV 是和手机 App 一样的竖屏界面。平板、电视、盒子不受影响，还是原来的样子。

想和以前一样横着用：**设置 → 外观 → 手机界面**，选「横屏（和电视一样）」。之后想换回竖屏，在 **设置 → 界面 → 手机界面** 里选「竖屏」。

## 首页

底下三个标签：「频道」「收藏」「设置」。

**频道**

- 点顶上的直播源名字，换到别的直播源。
- 点搜索，按名字找台。
- 点左下角的分组按钮，按分组看。
  - 长按一个分组：可以「分享这个分组」或「隐藏这个分组」。
  - 隐藏的分组在分组面板最底下点「恢复」。
- 往上翻列表时，分组按钮和底下的标签栏会收起来，往下翻再出现。
- 点一个台开始播放；长按一个台，选「加入收藏」。

**收藏**

收藏的台都在这里。它和电视上的「精选频道」是同一份，见 [老人小孩模式：精选与只看精选](07-favorites.md)。

## 播放页

上面是画面，下面是节目和换台。

- 顶栏：返回、收藏、换线路。配置好了 AI 字幕的，还有 AI 字幕按钮，见 [AI 字幕](09-ai-subtitle.md)。
- 「正在播」：现在的节目和播到哪儿了。
- 下面两颗按钮：
  - **分组名**：这个分组里的台，点一个就换过去；再点一下这颗按钮，展开分组面板换分组。
  - **节目单**：按天看节目。过去的节目点「回看」；回看时点「回到直播」回来。
- 回看时画面下面有进度条，可以拖动、暂停。有的回看地址不能拖，就不显示进度条。

## 全屏

把手机横过来，或者点一下画面再点全屏按钮，就是全屏播放。节目接着播，不会重新加载。按返回键回到竖屏。

| 操作 | 效果 |
|------|------|
| 点一下画面 | 出现按钮和信息，3 秒后自己收起 |
| 上下滑 | 换台 |
| 左半边左右滑 | 调亮度 |
| 右半边左右滑 | 调音量 |
| 双击 | 暂停 / 继续 |

点一下画面后能看到：

- 左上角：退出全屏、台名和现在的节目。
- 右上角：AI 字幕（配置好了才有）、轨道选择、小窗播放。
  - 轨道选择只在节目里有不止一条声音、不止一种画面，或者带字幕时才出现。字幕点正在用的那一条就是关掉。
- 左下角：画质和音质徽章，含义见 [播放与画面](06-playback.md)。
- 右下角：网速。
- 回看时最底下有进度条。
- 左边中间：锁。锁上后怎么点、怎么滑都没反应，点一下画面只露出锁，再点锁解开。

播不了时，画面上有「重试」和「换线路」。

全屏里没有电视上的选台列表、快捷菜单和分屏。要用这些，把「手机界面」换成「横屏（和电视一样）」。

## 设置

- **管理直播源**：点一个换过去；长按可以分享或删除。
- **添加直播源**：
  - 自动查找：查找局域网里的直播源。
  - 输入地址：填直播源网址。
  - 本地文件：选手机里的 m3u / txt 文件。手机没有文件选择功能时，会提示「这台设备不支持选取文件」。
  - 请求协助：请家人或朋友远程帮你添加，见 [添加直播源的四种方法](02-add-source.md#四请求协助)。
  - 手机上没有「手机扫码」这一项。
- **节目单**、**换台反转**、**主题颜色**、**手机界面**、**自动小窗播放**、**AI 字幕**、**关于**（版本、检查更新）。

这里只放了手机上用得着的设置。别的设置还在：把「手机界面」换成「横屏（和电视一样）」，在原来的设置里改。
