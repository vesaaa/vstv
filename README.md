**VsTV** 让你在 **智能电视、电视盒子、平板或手机** 上收看直播频道：选台、换台、多线路、节目单、回看、精选频道、分屏、AI 字幕等常见需求都可在应用内完成。

**本应用不内置、不提供任何直播源或节目内容**，首次安装后需要自行添加你已获得合法授权的直播源地址。

## 🌟 核心亮点

- **🚀 轻量快速**：常规安装包不足 10MB，没有多余的库。针对低配盒子（如 S905 系列）优化内存占用，启动快、换台快、操作流畅。
- **🛰️ 原生组播（电信 / 联通 / 移动 IPTV）**：
  - 直接播放 `udp://`、`rtp://` 组播地址，**不需要 udpxy 等转发服务**，盒子接入 IPTV 网络即可播放 4K 组播源。
  - 自动获取系统组播锁、加大接收缓冲，减少丢包和花屏。
- **🔗 多源合一，多线路自动切换**：可以添加多个直播源，不同来源的同名频道自动合并成多条线路；某条线路打不开时自动试下一条，并记住能用的那条。
- **👨‍👩‍👧‍👦 老人 / 儿童精选模式**：把常看的频道加入「精选」，打开「只看精选」后只显示这些频道，换台也只在精选里切换，长辈不再「找不到台」。
- **⏲️ 回看与时移**：适配运营商常见的 `catchup` 模板，最多回看 **7 天**；回看时可以拖动进度、快进快退，一键回到直播。
- **📺 分屏同看**：左右分屏或四宫格，最多同时看四路直播。
- **🔊 杜比与菁彩声**：支持杜比数字 / 杜比数字+、音频直通；安装菁彩声版后可播放 **菁彩声（Audio Vivid / AV3A）** 音频。
- **🔐 兼容加密频道**：支持直播源里常见的 ClearKey 加密频道，优先使用直播源自带的请求头。
- **🪟 小窗播放**：按主页键或切到别的应用时自动小窗继续播放（手机、平板默认开启）。

## 🚀 快速上手

> 详细的使用说明见 **[使用帮助](https://github.com/vesaaa/vstv/blob/main/docs/README.md)**：添加直播源、节目单与回看、精选与扩展频道、AI 字幕、常见问题等。

1. 在 **[Releases](https://github.com/vesaaa/vstv/releases)** 下载对应的安装包，安装到电视或盒子上（见下文「下载与安装」）。
2. 第一次打开时会自动弹出「添加直播源」，选一种方式添加：
   - **自动添加**：自动查找同一局域网里的 tvgo（默认端口 16677）和 rtp2httpd（默认端口 5140），选一下就能用；rtp2httpd 需要先在它的配置里设置好播放列表。
   - **手机扫码**：用手机扫电视上的二维码，在网页里填写直播源，一键推送到电视。
   - **输入地址**：用遥控器直接输入直播源地址。
   - **请求协助**：电视上显示一个 4 位数字，请家人或朋友在他们的 VsTV 上帮你添加。
3. 节目单在 **设置 → 节目单** 里选择：可以用内置的模板，也可以填自己的 XMLTV 地址。

以后要再添加直播源，在 **设置 → 直播源 → 添加直播源** 里操作即可。

## 🛠️ 功能使用说明

### 1. 运营商组播（UDP / RTP）
1. 在直播源里直接填写 `udp://@239.x.x.x:xxxx` 或 `rtp://239.x.x.x:xxxx` 这样的地址。
2. 电视 / 盒子需要连在 IPTV 网络上（通常接光猫的 iTV 口，或在路由器上配置好 VLAN）。
3. 其余不用任何设置，VsTV 会自动处理组播接收。

### 2. 多源合并
1. 添加多个直播源（比如一个是央视高清，一个是地方频道）。
2. 同名频道（如「CCTV1」）会自动合并，选台列表里显示为「线路 1 / 2 / 3…」，左右键即可切换。

### 3. 老人模式（只看精选）
1. **标记精选**：在选台列表里，长按确认键把频道加入精选。
2. **开启**：进入 **设置 → 精选与合并**，打开 **「只看精选」**。
3. **效果**：之后只显示精选频道，上下换台也只在精选里切换。

### 4. 快速切换直播源
播放时 **长按确认键**（触屏长按约 0.8 秒），弹出已保存的直播源列表，选一个立即切换，不用进设置。在列表里长按某个直播源还可以把它分享给别人。快捷菜单里也有同样的「切换直播源」入口。

### 5. 请求协助与分享直播源
- **请求协助**：在 **设置 → 直播源 → 添加直播源 → 请求协助**，电视上会显示一个 4 位数字。
- **帮别人添加**：协助者在自己的 VsTV 上长按频道分组或直播源，选 **「分享直播源」**，输入这 4 位数字，对方电视上确认后就添加好了。

### 6. AI 字幕
把外语节目实时翻译成中文字幕，中文节目也能直接出字幕。在 **设置 → AI 字幕 → 翻译服务** 里选择：

- **TVGO 本地翻译（推荐，免费）**：用自己小主机或 NAS 上开启了 AI 翻译的 tvgo 来翻译，**不用密钥、不花钱**，支持普通话、粤语、英语、日语、韩语。添加过这样的 tvgo 直播源后，看任何频道都能用它翻译；设置里会显示它的状态（已就绪、模型下载中、未开通等）。
- **阿里云百炼**：能自动识别节目语言，需要自己申请 API Key：
  1. 打开 **[阿里云百炼](https://bailian.aliyun.com)**，开通服务，**地域选「华北2（北京）」**（国际站的 Key 不能用）。
  2. 创建 **API Key**，并记下 **业务空间 ID**（形如 `ws-xxxxxxxx`）。
  3. 在 VsTV **设置 → AI 字幕** 填写；也可以选「用手机填写密钥」，扫码后在网页里粘贴。
  4. 费用由阿里云按收听时长收取，不看外语节目时建议关掉。

使用时在播放界面打开 **快捷菜单 → AI 字幕**，只对当前频道生效，换台后自动关闭。

说明：
- 开启后画面会比直播晚几秒（「字幕提前量」，3–8 秒可调），这样字幕能和声音对上。
- 字幕的大小、位置、显示方式（短句 / 长句）以及是否同时显示原文，都可以在设置里调整。
- 杜比音频在任何设备上都能翻译；菁彩声音频需要安装菁彩声版。
- 分屏播放和 DASH / RTSP 直播源暂不支持 AI 字幕。

### 7. 网页配置
同一局域网内，用手机或电脑浏览器打开 **`http://电视IP:1616`**，可以修改直播源、节目单等设置，和电视上的设置是同一份。具体地址和二维码在 **设置 → 网络** 里可以看到。

## 📡 直播源支持

支持常见的电视直播订阅格式：

- **标准 M3U 直播源**（最通用）
  - 典型结构：`#EXTM3U` + `#EXTINF` + 播放地址，支持 `catchup` 回看模板、请求头等常见扩展。
  - 例：`http://example.com/live.m3u`
- **TVBox / 影视仓风格 TXT 直播源**
  - 兼容 `分组名,#genre#` + `频道名,地址` 结构。
  - 支持单频道多线路（`地址1#地址2`）和分辨率后缀（如 `地址$1920×1080`，`$` 后的描述会自动忽略）。
  - 例：
    - `央视频道,#genre#`
    - `CCTV1,http://a.example/live1.m3u8#http://b.example/live1.m3u8`
- **tvgo**：小主机 / NAS 上运行的 tvgo 直播服务，可以用「自动添加」一键找到；开启 AI 翻译后还能提供免费的本地 AI 字幕。
- **rtp2httpd 播放列表**
  - 直接填写 rtp2httpd 输出的播放列表地址（如 `http://192.168.1.1:5140/playlist.m3u`），也可以用「自动添加」找到。
  - 列表里的相对路径（如 `/rtp/...`）会自动补全成完整地址。

### 播放协议

播放器基于 **Media3（ExoPlayer）**，按频道地址自动识别协议；服务端实际返回的格式和推断不一致时，会自动换一种方式重试。

| 协议 | 常见地址特征 | 说明 |
|------|-------------|------|
| **UDP / RTP** | `udp://`、`rtp://` | 原生组播，无需转发 |
| **HLS** | `.m3u8` | IPTV 直播最常见；可切换多条音轨 |
| **DASH** | `.mpd` | MPEG-DASH |
| **Smooth Streaming** | `.ism`、`Manifest` | 微软平滑流 |
| **RTSP** | `rtsp://` | 包括运营商 RTSP 回看 / 点播 |
| **单文件直链** | `.mp4`、`.mkv` 等 | 渐进式播放 |

**解码**：内置 [mediax](https://github.com/vesaaa/mediax)（基于 FFmpeg 的扩展软解），硬解不支持时自动用软解兜底，提升 H.265 / HEVC 等片源在不同设备上的兼容性。菁彩声版额外内置 AV3A（Audio Vivid）软解。实际能否播放仍取决于片源编码和设备性能。

## 📦 下载与安装

在 **[Releases](https://github.com/vesaaa/vstv/releases)** 下载 APK。每个版本包含 **四个** 安装包，按设备选择：

| 文件 | 适用说明 |
|------|----------|
| **`vstv-<版本>-arm.apk`** | **默认选择**，适合绝大多数电视、盒子、手机（ARM 设备）。桌面名 **VsTV**。 |
| **`vstv-<版本>-arm-av3a.apk`** | **菁彩声版**：在 `arm` 版基础上内置菁彩声（AV3A）软解，体积更大；需要播放菁彩声频道时安装，可以直接覆盖安装 `arm` 版。 |
| **`vstv-<版本>-x86_64.apk`** | 适用于 **x86_64** 设备（如部分电脑上的安卓模拟器）；不含菁彩声软解。 |
| **`vstv-<版本>-HarmonyOS.apk`** | **华为智慧屏** 等需要不同包名时使用，桌面名 **Z视介**；与常规版数据不互通，请不要混装升级包。 |

**应用内更新**：在 **设置 → 关于** 检查更新，会自动下载和你当前安装的版本类型、设备架构匹配的安装包（装的是菁彩声版，就只会更新到菁彩声版）。

## 📱 适用环境

- **设备**：常见品牌电视和盒子（TCL、海信、酷开、小米、华为智慧屏、荣耀等），以及安卓手机、平板；部分鸿蒙设备通过安卓兼容层运行。
- **系统**：Android 5 及以上；实际播放效果取决于设备解码能力和片源。
- **不需要谷歌服务**：可以通过 U 盘、远程推送、网页或文件管理器安装 APK。

### 使用前建议了解

- 支持 **http** 明文地址，方便使用常见的 IPTV 和节目单链接。
- 网页配置页使用 **1616 端口**，页面依赖公共 CDN（如 jsDelivr），请确保网络可以访问。
- Android 8 及以上需要在系统里允许本应用 **安装未知应用**，否则应用内更新可能没有反应。
- **开机自启** 依赖系统广播，部分品牌还需要在系统设置里允许自启动 / 后台运行。
